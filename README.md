# Pharus sample apps

This repository contains sample apps that can be used to run bechmarks with [Pharus](https://github.com/loriswit/pharus).

## Usage

To run a benchmark and generate a report, clone this repository and run the following command:

```
bin/pharus run [options] <path-to-app> <user-flow>
```

## Reports

You can find generated reports in [this repository](https://github.com/loriswit/pharus-reports).

## Troubleshooting

To browse a sepcific version of a web app in a web browser, run:

```
bin/pharus browse <path-to-app> <pattern>
```
